# 25F-0080_AI
Assignment 3 Programming For Artificial Intelligence

Difficulty:
            Q6 is the hardest because it asks for six different charts in one figure, each with its own special rule (twin axis, outside legend, arrow, colorbar, inset), so one small miss costs marks. It also depends on the results of Q3, Q4 and Q5, so any earlier mistake breaks it. And unlike the other questions, the code can run without an error and still look wrong (overlapping labels, a squashed layout), so you have to check the picture yourself and then explain what it shows using your own numbers.
